## LinkedIn Post Announcement
🚀 **Excited to share my latest Machine Learning project: AI Resume Analyzer & Job Recommendation System!** 📄

As I prepare for opportunities like the TCS Prime and Machine Learning Internships, I wanted to build a tool that solves a real-world problem: helping candidates optimize their resumes for ATS (Applicant Tracking Systems). 

🛠️ **What it does:**
- Extracts text from uploaded PDF resumes using `pdfplumber`.
- Cleans and preprocesses data using NLP (`NLTK`).
- Calculates an ATS Match Score against specific Job Descriptions using TF-IDF and Cosine Similarity (`Scikit-Learn`).
- Highlights missing skills and recommends alternative job roles.

💻 **Tech Stack:**
Python | FastAPI (Backend) | Streamlit (Frontend UI) | Docker (Containerization)

By decoupling the frontend and backend and containerizing the app with Docker, I learned a lot about modern software architecture and deploying ML models in production.
